Linux 서버를 관리하면서 자주 사용하는 명령어를 정리한다.

이번 글에서는 Linux의 기본적인 디렉터리 이동부터 파일 관리, 권한 설정, 프로세스 확인, 디스크 사용량 확인, 네트워크 연결 확인, 로그 분석까지 실무에서 자주 사용하는 명령어를 정리했다.

특히 데이터베이스 서버를 운영하거나 Oracle, SharePlex와 같은 솔루션을 관리할 때 활용할 수 있는 명령어도 함께 살펴본다.

---

# 1. Linux란?

**Linux는 서버, PC, 클라우드 환경 등에서 널리 사용되는 오픈소스 운영체제 커널**이다.

Linux 기반 운영체제에서는 명령어를 사용해 파일과 디렉터리를 관리하고, 프로세스를 확인하거나 네트워크 상태를 점검할 수 있다.

예를 들어 서버에서 문제가 발생했을 때 다음과 같은 작업을 수행할 수 있다.

```text
서버 접속
   ↓
프로세스 확인
   ↓
디스크 사용량 확인
   ↓
로그 분석
   ↓
문제 원인 파악
```

Linux 명령어를 익혀 두면 서버 장애를 분석하거나 데이터베이스 운영 작업을 수행할 때 도움이 된다.

# 2. Linux 터미널이란?

Linux 터미널은 명령어를 입력하고 실행 결과를 확인하는 인터페이스다.

예를 들어 다음과 같이 명령어를 입력할 수 있다.

```bash
pwd
```

실행 결과:

```text
/home/oracle
```

현재 작업 중인 디렉터리의 경로를 확인할 수 있다.

명령어를 실행하면 결과가 출력되거나 파일 생성, 디렉터리 이동 등의 작업이 수행된다.

# 3. 현재 위치 및 디렉터리 관리

## 3.1 `pwd` - 현재 경로 확인

현재 작업 중인 디렉터리의 절대 경로를 출력한다.

```bash
pwd
```

실행 결과:

```text
/home/oracle
```

현재 어느 디렉터리에서 작업하고 있는지 확인할 때 사용한다.

## 3.2 `ls` - 파일 및 디렉터리 목록 확인

현재 디렉터리에 존재하는 파일과 디렉터리를 확인한다.

```bash
ls
ls -l
ls -al
ls -lh
```

주요 옵션:

| 옵션 | 설명 |
| --- | --- |
| `-l` | 파일 권한, 소유자, 크기 등 상세 정보 출력 |
| `-a` | 숨김 파일 포함 |
| `-h` | 파일 크기를 읽기 쉬운 단위로 표시 |

예를 들어 `ls -al`을 실행하면 숨김 파일을 포함한 상세 목록을 확인할 수 있다.

## 3.3 `cd` - 디렉터리 이동

다른 디렉터리로 이동할 때 사용한다.

```bash
cd /home/oracle
cd ..
cd ~
```

- `/home/oracle`: 지정한 경로로 이동
- `..`: 상위 디렉터리로 이동
- `~`: 현재 사용자의 홈 디렉터리로 이동

## 3.4 `mkdir` - 디렉터리 생성

새로운 디렉터리를 생성한다.

```bash
mkdir backup
mkdir -p /home/oracle/backup/data
```

`-p` 옵션을 사용하면 필요한 상위 디렉터리도 함께 생성한다.

## 3.5 `touch` - 파일 생성

빈 파일을 생성하거나 기존 파일의 수정 시간을 변경한다.

```bash
touch test.txt
```

파일이 존재하지 않으면 새 파일이 생성된다.

# 4. 파일 내용 확인

## 4.1 `cat` - 파일 내용 출력

파일의 전체 내용을 출력한다.

```bash
cat test.txt
```

설정 파일이나 짧은 텍스트 파일의 내용을 확인할 때 사용한다.

## 4.2 `less` - 파일 내용 페이지 단위로 확인

내용이 긴 파일을 페이지 단위로 확인한다.

```bash
less application.log
```

주요 조작 방법:

| 키 | 기능 |
| --- | --- |
| `Space` | 다음 페이지 |
| `b` | 이전 페이지 |
| `/ERROR` | ERROR 검색 |
| `n` | 다음 검색 결과 |
| `q` | 종료 |

로그 파일이 크거나 설정 파일의 특정 내용을 찾아야 할 때 유용하다.

## 4.3 `head` - 파일 앞부분 확인

파일의 첫 부분을 출력한다.

```bash
head application.log
head -n 20 application.log
```

기본적으로 앞부분 10줄을 출력하며 `-n` 옵션으로 줄 수를 지정할 수 있다.

## 4.4 `tail` - 파일 마지막 부분 확인

파일의 마지막 부분을 출력한다.

```bash
tail application.log
tail -n 100 application.log
tail -f application.log
```

- `-n 100`: 마지막 100줄 출력
- `-f`: 파일에 추가되는 내용을 실시간으로 확인

예를 들어 프로그램이 실행되는 동안 로그가 어떻게 쌓이는지 확인하려면 `tail -f`를 사용한다.

종료하려면 `Ctrl + C`를 누른다.

# 5. 파일 복사, 이동 및 삭제

## 5.1 `cp` - 파일 복사

파일이나 디렉터리를 복사한다.

```bash
cp source.txt backup.txt
cp -r source_dir backup_dir
```

- 첫 번째 명령어: `source.txt`를 `backup.txt`로 복사
- 두 번째 명령어: 디렉터리와 하위 내용을 복사

## 5.2 `mv` - 파일 이동 및 이름 변경

파일을 이동하거나 이름을 변경한다.

```bash
mv old.txt new.txt
mv backup.txt /home/oracle/
```

파일 이름 변경과 디렉터리 이동 모두 `mv` 명령어로 처리할 수 있다.

## 5.3 `rm` - 파일 및 디렉터리 삭제

파일이나 디렉터리를 삭제한다.

```bash
rm test.txt
rm -r test_dir
```

`-r` 옵션은 디렉터리와 그 하위 내용을 삭제한다.

**주의:** `rm -rf`는 확인 없이 파일이나 디렉터리를 강제로 삭제할 수 있다. 운영 서버에서는 삭제 대상 경로를 반드시 확인해야 한다.

# 6. 파일 검색 및 내용 검색

## 6.1 `find` - 파일 및 디렉터리 검색

특정 경로에서 조건에 맞는 파일을 검색한다.

```bash
find /home/oracle -name "*.log"
find /home/oracle -type f -name "*.log"
find /home/oracle -type d -name "backup"
```

주요 옵션:

| 옵션 | 설명 |
| --- | --- |
| `-name` | 파일 또는 디렉터리 이름으로 검색 |
| `-type f` | 일반 파일만 검색 |
| `-type d` | 디렉터리만 검색 |

예를 들어 특정 경로 아래에 있는 모든 로그 파일을 찾을 때 활용할 수 있다.

## 6.2 `grep` - 파일 내용 검색

파일 내부에서 특정 문자열을 검색한다.

```bash
grep "ERROR" application.log
grep -i "error" application.log
grep -n "ORA-" application.log
grep -in "ORA-" application.log
```

주요 옵션:

- `-i`: 대소문자 구분 없이 검색
- `-n`: 검색된 줄 번호 표시

Oracle 오류 코드가 포함된 로그를 찾는 경우:

```bash
grep -in "ORA-" application.log
```

특정 오류가 발생한 위치를 빠르게 확인할 수 있다.

## 6.3 `which` - 명령어 경로 확인

명령어가 어느 경로에 존재하는지 확인한다.

```bash
which sqlplus
which sp_ctrl
```

명령어가 검색되지 않는다면 설치 여부와 `PATH` 환경변수를 확인할 수 있다.

# 7. 파일 권한 및 소유자 관리

Linux에서는 파일마다 읽기, 쓰기, 실행 권한을 설정할 수 있다.

## 7.1 `chmod` - 권한 변경

파일 또는 디렉터리의 권한을 변경한다.

```bash
chmod 755 script.sh
chmod 644 config.txt
```

권한 숫자의 의미:

| 숫자 | 권한 |
| --- | --- |
| 4 | 읽기(Read) |
| 2 | 쓰기(Write) |
| 1 | 실행(Execute) |
| 7 | 읽기 + 쓰기 + 실행 |
| 6 | 읽기 + 쓰기 |
| 5 | 읽기 + 실행 |

예를 들어 `755`는 소유자에게 읽기, 쓰기, 실행 권한을 부여하고 그룹과 기타 사용자에게 읽기 및 실행 권한을 부여한다.

## 7.2 `chown` - 소유자 변경

파일이나 디렉터리의 소유자 및 그룹을 변경한다.

```bash
chown oracle:oinstall test.txt
chown -R oracle:oinstall /home/oracle/backup
```

- `oracle`: 변경할 소유자
- `oinstall`: 변경할 그룹
- `-R`: 하위 파일 및 디렉터리까지 적용

Oracle 관련 파일의 소유권이나 그룹 권한을 확인하고 변경할 때 활용할 수 있다.

## 7.3 `sudo` - 관리자 권한으로 명령 실행

현재 사용자에게 허용된 범위에서 관리자 권한으로 명령어를 실행한다.

```bash
sudo ls /root
sudo systemctl status sshd
```

관리자 권한이 필요한 작업에 사용한다. 단, 권한 설정과 서버 정책에 따라 실행 가능 여부가 달라진다.

# 8. 프로세스 확인 및 관리

## 8.1 `ps` - 실행 중인 프로세스 확인

현재 실행 중인 프로세스를 확인한다.

```bash
ps -ef
ps -ef | grep oracle
ps -ef | grep pmon
```

Oracle 데이터베이스의 PMON 프로세스나 특정 프로그램이 실행 중인지 확인할 때 활용할 수 있다.

## 8.2 `top` - 실시간 시스템 상태 확인

CPU, 메모리 및 프로세스별 자원 사용량을 확인한다.

```bash
top
```

실행 중인 프로세스의 자원 사용 현황을 실시간으로 확인할 수 있다.

종료하려면 `q`를 누른다.

## 8.3 `kill` - 프로세스 종료 요청

특정 PID에 종료 신호를 전달한다.

```bash
kill 12345
kill -9 12345
```

기본 `kill`은 일반적으로 정상 종료를 요청하고, `kill -9`는 프로세스를 강제로 종료한다.

운영 중인 데이터베이스나 복제 솔루션의 프로세스를 종료할 때는 서비스에 미치는 영향을 먼저 확인해야 한다.

# 9. 디스크 및 메모리 사용량 확인

## 9.1 `df` - 파일시스템 사용량 확인

파일시스템의 전체 용량과 사용량을 확인한다.

```bash
df -h
df -h /home
```

`-h` 옵션을 사용하면 KB, MB, GB 등의 단위로 용량을 확인할 수 있다.

## 9.2 `du` - 디렉터리별 용량 확인

특정 디렉터리가 사용하는 용량을 확인한다.

```bash
du -sh /home/oracle
du -sh /home/oracle/*
```

- `-s`: 전체 합계만 출력
- `-h`: 읽기 쉬운 단위로 표시

디스크 공간이 부족할 때 어떤 디렉터리가 많은 용량을 사용하는지 확인할 수 있다.

## 9.3 `free` - 메모리 사용량 확인

시스템의 메모리와 스왑 사용량을 확인한다.

```bash
free -h
```

전체 메모리, 사용 중인 메모리, 사용 가능한 메모리 등을 확인할 수 있다.

# 10. 네트워크 및 포트 확인

## 10.1 `ping` - 네트워크 응답 확인

대상 서버에 ICMP 요청을 보내 응답 여부를 확인한다.

```bash
ping 192.168.3.112
```

응답이 없더라도 ICMP 차단이나 방화벽 정책 때문일 수 있으므로 네트워크 연결이 완전히 끊겼다고 단정할 수는 없다.

## 10.2 `ss` - 포트 및 소켓 확인

서버에서 대기 중인 포트와 네트워크 소켓을 확인한다.

```bash
ss -lntp
ss -lntp | grep 2100
```

주요 옵션:

| 옵션 | 설명 |
| --- | --- |
| `-l` | 대기 중인 소켓 |
| `-n` | 숫자 형태로 주소와 포트 표시 |
| `-t` | TCP 소켓 |
| `-p` | 관련 프로세스 정보 |

SharePlex와 같이 특정 TCP 포트를 사용하는 프로그램의 대기 상태를 확인할 때 활용할 수 있다.

## 10.3 `nc` - TCP 포트 연결 테스트

대상 서버의 특정 TCP 포트에 연결할 수 있는지 확인한다.

```bash
nc -zv 192.168.3.112 2100
```

대상 IP와 포트에 연결할 수 있는지 확인할 때 사용한다.

단, 연결 실패만으로 방화벽이 원인이라고 확정할 수는 없다. 서비스 상태, 라우팅, 방화벽 정책 등을 함께 확인해야 한다.

## 10.4 `curl` - HTTP 응답 확인

HTTP 서버의 응답 헤더를 확인한다.

```bash
curl -I http://192.168.3.112:8080
```

웹 서비스나 관리 콘솔의 HTTP 응답을 확인할 때 사용할 수 있다.

# 11. 로그 확인 및 분석

## 11.1 `tail -f` - 실시간 로그 확인

로그 파일에 추가되는 내용을 실시간으로 확인한다.

```bash
tail -f application.log
```

프로그램을 실행하면서 로그가 어떻게 기록되는지 확인할 때 유용하다.

## 11.2 `grep` - 오류 메시지 검색

로그에서 특정 오류 메시지를 검색한다.

```bash
grep -in "ERROR" application.log
grep -in "ORA-" application.log
```

Oracle 오류 코드나 애플리케이션 오류를 빠르게 검색할 수 있다.

## 11.3 `journalctl` - 시스템 서비스 로그 확인

systemd 기반 Linux에서 서비스 및 시스템 로그를 확인한다.

```bash
journalctl -xe
journalctl -u sshd
journalctl --since "1 hour ago"
```

- `-u`: 특정 서비스 로그 확인
- `--since`: 지정한 시점 이후의 로그 확인
- `-xe`: 최근 로그와 오류 관련 정보 확인

서비스 장애가 발생했을 때 관련 로그를 확인하는 데 활용할 수 있다.

# 12. 압축 및 파일 전송

## 12.1 `tar` - 파일 및 디렉터리 압축

여러 파일과 디렉터리를 하나의 아카이브로 묶거나 압축한다.

```bash
tar -cvf backup.tar backup_dir/
tar -czvf backup.tar.gz backup_dir/
tar -tvf backup.tar
tar -xzvf backup.tar.gz
```

주요 옵션:

| 옵션 | 설명 |
| --- | --- |
| `-c` | 아카이브 생성 |
| `-x` | 아카이브 해제 |
| `-v` | 처리 과정 출력 |
| `-f` | 아카이브 파일 지정 |
| `-z` | gzip 압축 사용 |

## 12.2 `gzip` - 파일 압축

파일을 gzip 형식으로 압축한다.

```bash
gzip application.log
gzip -d application.log.gz
```

일반적으로 압축 시 원본 파일은 `.gz` 파일로 대체된다.

## 12.3 `scp` - 서버 간 파일 전송

SSH를 이용해 로컬과 원격 서버 간 파일을 전송한다.

```bash
scp backup.dmp oracle@192.168.3.112:/home/oracle/
scp oracle@192.168.3.112:/home/oracle/backup.dmp .
```

첫 번째 명령어는 로컬 파일을 원격 서버로 전송한다.

두 번째 명령어는 원격 서버의 파일을 현재 디렉터리로 가져온다.

Oracle Data Pump로 생성한 덤프 파일을 다른 서버로 이동할 때도 활용할 수 있다.

# 13. 실무에서 자주 사용하는 명령어 조합

개별 명령어뿐 아니라 여러 명령어를 조합하면 작업을 더 효율적으로 수행할 수 있다.

## 13.1 로그에서 오류 검색

```bash
grep -in "ERROR" application.log
```

대소문자를 구분하지 않고 ERROR가 포함된 줄을 검색한다.

## 13.2 로그 마지막 100줄 확인

```bash
tail -n 100 application.log
```

최근 로그를 빠르게 확인할 수 있다.

## 13.3 오류 로그 실시간 확인

```bash
tail -f application.log | grep --line-buffered -i "error"
```

로그가 추가될 때 ERROR가 포함된 줄을 실시간으로 확인한다.

## 13.4 디스크 사용량 확인

```bash
df -h
du -sh /home/oracle/*
```

파일시스템의 전체 사용량과 하위 디렉터리별 사용량을 함께 확인한다.

## 13.5 특정 프로세스 확인

```bash
ps -ef | grep '[o]ra_pmon'
```

Oracle PMON 프로세스가 있는지 확인한다. 검색 명령어 자체가 결과에 포함되는 것을 줄일 수 있다.

## 13.6 특정 포트 확인

```bash
ss -lntp | grep 2100
```

해당 포트에서 대기 중인 TCP 소켓이 있는지 확인한다.

## 13.7 파일 검색 후 오류 확인

```bash
find /home/oracle -type f -name "*.log"
grep -in "ORA-" /home/oracle/application.log
```

첫 번째 명령어는 로그 파일을 찾고, 두 번째 명령어는 지정한 로그 파일에서 Oracle 오류를 검색한다.

# 15. 전체 작업 흐름

Linux 서버에서 장애를 확인하는 상황을 예로 들면 다음과 같은 순서로 작업할 수 있다.

```text
서버 접속
   │
   ▼
df -h
   │
   ▼
디스크 사용량 확인
   │
   ▼
ps -ef
   │
   ▼
프로세스 실행 상태 확인
   │
   ▼
tail / grep
   │
   ▼
로그 확인 및 오류 검색
   │
   ▼
ss / nc
   │
   ▼
포트 및 네트워크 연결 확인
```

모든 장애가 동일한 순서로 해결되는 것은 아니지만, 기본적인 서버 상태를 점검할 때 활용할 수 있는 흐름이다.

# 16. Linux 명령어를 익혀야 하는 이유

Linux 명령어는 단순히 파일을 관리하는 용도로만 사용되지 않는다.

서버 운영에서는 프로세스, 디스크, 메모리, 네트워크, 로그를 확인하는 작업이 반복적으로 발생한다.

특히 데이터베이스 서버를 운영할 때는 다음 명령어를 우선적으로 익히는 것이 좋다.

- `ps`, `top`: 프로세스 및 자원 사용 현황 확인
- `df`, `du`, `free`: 디스크 및 메모리 점검
- `tail`, `grep`, `journalctl`: 로그 분석
- `ss`, `nc`: 포트 및 네트워크 연결 확인
- `chmod`, `chown`: 파일 권한 및 소유권 관리
- `tar`, `scp`: 파일 압축 및 서버 간 전송

명령어의 사용법뿐 아니라 각 명령어가 어떤 상황에서 필요한지 이해하는 것이 중요하다.
