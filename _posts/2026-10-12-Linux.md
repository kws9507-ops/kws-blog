Linux 서버를 운영하거나 Oracle, SharePlex와 같은 데이터베이스 솔루션을 관리할 때는 기본적인 Linux 명령어를 알아야 한다.

이번 글에서는 실무에서 자주 사용하는 Linux 명령어를 파일 관리, 검색, 권한, 프로세스, 디스크, 네트워크, 로그 확인 등의 주제로 나누어 정리한다.

## 1. 현재 위치 및 디렉터리 관리

### 1.1 `pwd` - 현재 경로 확인

현재 작업 중인 디렉터리의 절대 경로를 출력한다.

```bash
pwd
```

### 1.2 `ls` - 파일 및 디렉터리 목록 확인

```bash
ls
ls -l
ls -al
ls -lh
```

- `-l`: 상세 정보 출력
- `-a`: 숨김 파일 포함
- `-h`: 파일 크기를 읽기 쉬운 단위로 표시

### 1.3 `cd` - 디렉터리 이동

```bash
cd /home/oracle
cd ..
cd ~
```

- `..`: 상위 디렉터리
- `~`: 현재 사용자의 홈 디렉터리

### 1.4 `mkdir` - 디렉터리 생성

```bash
mkdir test
mkdir -p /home/oracle/backup/data
```

`-p` 옵션은 상위 디렉터리가 없는 경우에도 필요한 디렉터리를 함께 생성한다.

### 1.5 `touch` - 파일 생성 및 수정 시간 변경

```bash
touch test.txt
```

파일이 없으면 빈 파일을 생성하고, 이미 있으면 수정 시간을 변경한다.

## 2. 파일 확인 및 관리

### 2.1 `cat` - 파일 내용 출력

```bash
cat test.txt
```

파일 전체 내용을 터미널에 출력한다. 내용이 긴 로그 파일에는 `less`를 사용하는 것이 편리하다.

### 2.2 `less` - 파일 내용 페이지 단위로 확인

```bash
less application.log
```

- `Space`: 다음 페이지
- `b`: 이전 페이지
- `/ERROR`: ERROR 검색
- `n`: 다음 검색 결과
- `q`: 종료

### 2.3 `head` - 파일 앞부분 확인

```bash
head application.log
head -n 20 application.log
```

기본적으로 앞부분 10줄을 출력하며, `-n`으로 출력할 줄 수를 지정할 수 있다.

### 2.4 `tail` - 파일 마지막 부분 확인

```bash
tail application.log
tail -n 100 application.log
tail -f application.log
```

`-f` 옵션은 파일에 새로운 로그가 추가될 때 실시간으로 확인할 때 사용한다. 종료하려면 `Ctrl + C`를 누른다.

### 2.5 `cp` - 파일 복사

```bash
cp source.txt backup.txt
cp -r source_dir backup_dir
```

`-r` 옵션은 디렉터리와 그 하위 내용을 복사할 때 사용한다.

### 2.6 `mv` - 파일 이동 및 이름 변경

```bash
mv old.txt new.txt
mv backup.txt /home/oracle/
```

파일 이름을 변경하거나 다른 디렉터리로 이동할 때 사용한다.

### 2.7 `rm` - 파일 및 디렉터리 삭제

```bash
rm test.txt
rm -r test_dir
```

**주의:** `rm`으로 삭제한 파일은 일반적인 휴지통으로 이동하지 않는다. 특히 `rm -rf`는 대상 경로를 반드시 확인한 뒤 사용해야 한다.

## 3. 파일 검색 및 내용 검색

### 3.1 `find` - 파일 및 디렉터리 검색

```bash
find /home/oracle -name "*.log"
find /home/oracle -type f -name "*.log"
find /home/oracle -type d -name "backup"
```

- `-name`: 이름으로 검색
- `-type f`: 일반 파일만 검색
- `-type d`: 디렉터리만 검색

### 3.2 `grep` - 파일 내용 검색

```bash
grep "ERROR" application.log
grep -i "error" application.log
grep -n "ORA-" application.log
grep -in "ORA-" application.log
```

- `-i`: 대소문자 구분 없이 검색
- `-n`: 해당 줄 번호 표시

여러 로그 파일에서 검색할 수도 있다.

```bash
grep -in "ERROR" *.log
```

### 3.3 `which` - 명령어 실행 경로 확인

```bash
which sqlplus
which sp_ctrl
```

명령어가 어느 경로에 설치되어 있는지 확인할 때 사용한다. 명령어를 찾지 못하면 PATH 설정이나 설치 여부를 확인한다.

## 4. 파일 권한 및 소유자 관리

### 4.1 `chmod` - 권한 변경

```bash
chmod 755 script.sh
chmod 644 config.txt
```

Linux 권한은 소유자(User), 그룹(Group), 기타 사용자(Others)로 구분된다.

| 숫자 | 권한 |
|---|---|
| 7 | 읽기 + 쓰기 + 실행 |
| 6 | 읽기 + 쓰기 |
| 5 | 읽기 + 실행 |
| 4 | 읽기 |

예를 들어 `755`는 소유자에게 모든 권한을 부여하고, 그룹과 기타 사용자에게 읽기 및 실행 권한을 부여한다.

### 4.2 `chown` - 파일 소유자 변경

```bash
chown oracle:oinstall test.txt
chown -R oracle:oinstall /home/oracle/backup
```

- `oracle`: 변경할 소유자
- `oinstall`: 변경할 그룹
- `-R`: 하위 파일 및 디렉터리까지 적용

소유권 변경에는 일반적으로 관리자 권한이 필요하다. 운영 서버에서는 대상 경로와 변경 범위를 먼저 확인해야 한다.

### 4.3 `sudo` - 관리자 권한으로 명령 실행

```bash
sudo ls /root
sudo systemctl status sshd
```

현재 사용자에게 허용된 범위에서 관리자 권한으로 명령어를 실행한다.

## 5. 프로세스 확인 및 관리

### 5.1 `ps` - 실행 중인 프로세스 확인

```bash
ps -ef
ps -ef | grep oracle
ps -ef | grep pmon
```

Oracle 인스턴스의 PMON 프로세스나 특정 프로그램의 실행 여부를 확인할 때 활용할 수 있다.

### 5.2 `top` - 실시간 시스템 상태 확인

```bash
top
```

CPU 사용률, 메모리 사용량, 프로세스별 자원 사용 현황을 확인한다. 종료하려면 `q`를 누른다.

### 5.3 `kill` - 프로세스 종료 요청

```bash
kill 12345
kill -9 12345
```

기본 `kill`은 일반적으로 SIGTERM을 전달해 정상 종료를 요청한다. `kill -9`는 SIGKILL로 강제 종료하므로 정상 종료가 되지 않을 때 신중하게 사용해야 한다.

운영 프로세스를 종료하기 전에는 PID와 해당 프로세스의 역할을 반드시 확인한다.

## 6. 디스크 및 메모리 확인

### 6.1 `df` - 파일시스템 사용량 확인

```bash
df -h
df -h /home
```

파일시스템별 전체 용량, 사용량, 남은 용량을 확인한다.

### 6.2 `du` - 디렉터리별 용량 확인

```bash
du -sh /home/oracle
du -sh /home/oracle/*
```

- `-s`: 전체 합계만 표시
- `-h`: 읽기 쉬운 단위로 표시

디스크 공간이 부족할 때 용량이 큰 디렉터리를 찾는 데 유용하다.

### 6.3 `free` - 메모리 사용량 확인

```bash
free -h
```

전체 메모리, 사용 중인 메모리, 사용 가능한 메모리 및 스왑 사용량을 확인한다.

## 7. 네트워크 확인

### 7.1 `ping` - 네트워크 응답 확인

```bash
ping 192.168.3.112
```

대상 서버의 ICMP 응답을 확인한다. 응답이 없더라도 방화벽 정책이나 ICMP 차단 때문일 수 있으므로 네트워크 연결이 완전히 끊겼다고 단정할 수는 없다.

### 7.2 `ss` - 포트 및 소켓 확인

```bash
ss -lntp
ss -lntp | grep 2100
```

- `-l`: 대기 중인 소켓
- `-n`: 포트 번호를 숫자로 표시
- `-t`: TCP 소켓
- `-p`: 관련 프로세스 정보

SharePlex를 운영할 때는 설정된 포트가 실제로 대기 상태인지 확인하는 데 활용할 수 있다. 프로세스 정보는 권한에 따라 표시되지 않을 수 있다.

### 7.3 `curl` - HTTP 연결 테스트

```bash
curl -I http://192.168.3.112:8080
```

HTTP 서버에 연결해 응답 헤더를 확인한다. HTTP 서비스가 아닌 포트에는 적합하지 않다.

### 7.4 `nc` - TCP 포트 연결 확인

```bash
nc -zv 192.168.3.112 2100
```

대상 서버의 TCP 포트에 연결할 수 있는지 확인한다. `nc`가 설치되어 있어야 하며, 연결 실패만으로 방화벽 문제라고 확정할 수는 없다.

## 8. 로그 확인 및 시스템 상태 점검

### 8.1 `tail -f` - 실시간 로그 확인

```bash
tail -f /var/log/messages
```

로그에 새로운 내용이 기록되는지 실시간으로 확인한다.

### 8.2 `grep` - 오류 로그 검색

```bash
grep -in "error" /var/log/messages
grep -in "ORA-" application.log
```

Oracle 오류 코드나 프로그램의 오류 메시지를 검색할 때 유용하다.

### 8.3 `journalctl` - systemd 로그 확인

```bash
journalctl -xe
journalctl -u sshd
journalctl --since "1 hour ago"
```

- `-u`: 특정 서비스의 로그 확인
- `--since`: 지정한 시점 이후의 로그 확인
- `-xe`: 최근 로그와 오류 관련 정보를 확인

서비스 장애가 발생했을 때 서비스 로그와 시스템 로그를 함께 확인하면 원인 분석에 도움이 된다.

## 9. 압축 및 파일 전송

### 9.1 `tar` - 파일 및 디렉터리 압축

```bash
tar -cvf backup.tar backup_dir/
tar -czvf backup.tar.gz backup_dir/
tar -tvf backup.tar
tar -xzvf backup.tar.gz
```

- `-c`: 아카이브 생성
- `-x`: 아카이브 해제
- `-v`: 처리 과정 표시
- `-f`: 파일 이름 지정
- `-z`: gzip 압축 사용

### 9.2 `gzip` - 파일 압축

```bash
gzip application.log
gzip -d application.log.gz
```

기본적으로 압축 시 원본 파일이 압축 파일로 대체된다.

### 9.3 `scp` - 서버 간 파일 전송

```bash
scp backup.dmp oracle@192.168.3.112:/home/oracle/
scp oracle@192.168.3.112:/home/oracle/backup.dmp .
```

첫 번째 명령어는 로컬 파일을 원격 서버로 전송하고, 두 번째는 원격 서버의 파일을 현재 디렉터리로 가져온다.

접속 계정, SSH 포트, 대상 경로의 권한을 확인해야 한다.

## 10. 실무에서 자주 사용하는 명령어 조합

### 로그에서 오류 찾기

```bash
grep -in "ERROR" application.log
```

### 로그 마지막 100줄 확인

```bash
tail -n 100 application.log
```

### 특정 로그의 오류를 실시간으로 확인

```bash
tail -f application.log | grep --line-buffered -i "error"
```

### 디스크 사용량 확인

```bash
df -h
du -sh /home/oracle/*
```

### 특정 프로세스 확인

```bash
ps -ef | grep '[o]ra_pmon'
```

### 특정 포트 대기 상태 확인

```bash
ss -lntp | grep 2100
```

### 파일을 검색한 후 오류 메시지 찾기

```bash
find /home/oracle -type f -name "*.log"
grep -in "ORA-" /home/oracle/*.log
```

## 마무리

Linux 명령어는 단순히 외우는 것보다 실제 서버에서 목적에 맞게 사용하는 것이 중요하다.

특히 DB 서버 운영에서는 다음 항목을 우선적으로 익히는 것이 좋다.

- `ps`, `top`: 프로세스 및 자원 사용 현황 확인
- `df`, `du`, `free`: 디스크 및 메모리 점검
- `tail`, `grep`, `journalctl`: 로그 분석
- `ss`, `nc`: 네트워크 및 포트 연결 확인
- `chmod`, `chown`: 파일 권한과 소유권 관리
- `scp`, `tar`: 파일 전송 및 백업 관리

앞으로 Linux 명령어뿐 아니라 Oracle, SharePlex 운영 과정에서 활용한 명령어와 장애 대응 사례도 함께 정리할 예정이다.
